# Music Playlist Manager

The application allows users to manage a music library and organize songs into playlists.

## Technologies

- Java 21
- Apache Maven 3
- JavaFX 21
- JUnit 5
- Spotless

## Build

```bash
mvn clean compile
```

## Run

```bash
mvn javafx:run
```

## Test

```bash
mvn test
```

## Format Code

```bash
mvn spotless:apply
```

## Check Formatting

```bash
mvn spotless:check
```
